# PROTOCOL_MOTION_MAP — vollständige 10-Kapitel-Motion-Landkarte (V1)

Grundlage: vollständiger Read des **frozen** Protokolls (alle 10 Kapitel +
Abschluss; Ch07 nur aus sicher zugänglicher Struktur). Jeder Kandidat hat einen
klaren Zweck (WHY DOES THIS NEED TO MOVE?). Defaults laut Bible: **720p MP4,
muted loop, preload=none, Poster, MM/MECHANISM-Rahmung, Text als HTML/CSS-Overlay,
Audio = SILENT LOOP** sofern nicht anders vermerkt.

Dauer je Typ: MICRO ~3–6 s · MECHANISM ~5–10 s · HERO ~6–12 s.
Priorität: **P0 Signature · P1 High-Value Mechanism · P2 Useful · P3 Nice-to-have.**

Motion-Dichte ist **bewusst ungleich**: Money-Chapters (02/04/05/06/07/09/10)
tragen mehr hochwertige Motion; 01/03/08/Abschluss weniger, aber gezielt.
